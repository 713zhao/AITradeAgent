📋 3-STEP SETUP PROCESS:

STEP 1: Get Your Chat ID (2 minutes)
─────────────────────────────────────────
Run this command:
  
  python3 setup_telegram.py

Then in Telegram:
  1. Find your bot
  2. Send ANY message (Hi, Hello, etc.)
  3. The bot will respond with your CHAT ID
  4. Copy the Chat ID (just the numbers)
  5. Press Ctrl+C to exit


STEP 2: Update Configuration (1 minute)
─────────────────────────────────────────
Edit: config/finance.yaml

Find this section (around line 47):
  
  notifications:
    telegram:
      bot_token: "8694519756:AAGxp6d7Fho3-696h4ae4tHvjcVmtazQUOw"
      chat_id: ""  ← REPLACE THIS WITH YOUR CHAT ID

Replace empty chat_id with your actual Chat ID:
  
  chat_id: "123456789"  (your number will be different)


STEP 3: Verify & Restart (1 minute)
─────────────────────────────────────────
Test configuration:
  
  python3 test_telegram_config.py

Restart the service:
  
  pkill -f "run_finance_service.py"
  python3 run_finance_service.py

🤔 TROUBLESHOOTING:

  Q: Bot doesn't respond to setup?
  A: Try again - Telegram has rate limits. Wait 30 seconds and retry.

  Q: Can't find bot in Telegram?
  A: Make sure bot token is correct. Check config/finance.yaml

  Q: Messages not showing in Telegram?
  A: Verify chat_id is numeric only (like 123456789 not "123456789")
     Restart the service after updating.

  Q: Still having issues?
  A: Check logs: tail -f logs/finance_service.log | grep -i telegram
